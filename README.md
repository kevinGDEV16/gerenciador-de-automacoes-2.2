Automação desenvolvida em Python para realizar o login no aplicativo Urano, utilizado para enviar cargas e informações para balanças. O sistema preenche automaticamente usuário e senha, organiza as tarefas em uma fila e permite retomar o fluxo após a reinicialização do servidor ou computador.
Principais recursos
Preenchimento automático de usuário e senha;
Execução de automações de login em fila;
Inicialização automática com o Windows;
Logs em tempo real;
Importação de configurações em JSON;
Opção de iniciar a fila automaticamente;
Opção de fechar o aplicativo ao finalizar;
Scripts para instalação e remoção da inicialização automática;
Testes automatizados para validação das configurações e da fila.
Tecnologias utilizadas
Python, Tkinter, PyAutoGUI, PyGetWindow, JSON, PyInstaller e Pytest.
